# P5 输出格式规范 v2.1（output-formats）

- **PPTX（默认）**：16:9（13.33×7.5in）或 brief 指定 4:3；文字全可编辑（不转曲不贴图字）；图表原生（内嵌工作簿）；母版含页码与品牌色；`deck-vN.pptx`，终版冻为 `final.pptx`。
- **PDF**：终版 PPTX 经 LibreOffice `convert` 直转，不重排；检查超链接与嵌入字体；`final.pdf`。
- **两者都要**：先冻 PPTX（须已过 P4-final 放行），再转 PDF；报告写明一致性。
- **渲染目检链路**：优先直渲 PPTX；直渲黑则"终版 PPTX→PDF→渲 PDF"中转，结论等效；报告声明走哪条。
- **动画附录（taste motion 映射子集）**：标题按行擦除进入（≤2 行页）/ 图片擦除进入（一页一次）/ 同构多图 Morph·淡出切换 / closing 大字飞入（配静态版）/ 章节整页换场（静态即 move）。禁弹跳/旋转强调/无意义循环；进入"快进慢停"，离场更快；PDF/打印版自动静态。全 deck 至少一处切换，否则 still-page cap（design≤7）。
- **设计说明十项**：方向（名+seed）+ redraw 理由 + idea 句 + live thing + 终轮分+caps+短板 + 外来图许可链（题/者/许可/源页/署名位）+ 占位替换表 + 未检声明（4:3/手机/字体/事实源）+ 待换清单。没跑过的检查不许声称跑过。
- **P4-final 交付凭证**：必须随 PPTX 一并交付【首席品鉴验收报告】（平均分 ≥9.0）或【质检遗憾说明】（3 轮熔断）；附截屏链路（`qa-shot/chain.txt`）与轮次（`qa-round.json`）。
- 交付用 `present` 暴露最终文件 + 设计说明 + 验收报告（或遗憾说明）。
