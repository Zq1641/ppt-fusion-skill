# P1 脑爆对齐 — 提问库与话术 v2.1

一次只问 1–2 个问题。每个问题给 2–4 个选项（第一个为推荐并标注），最后加一句"也可以直接说你的想法"。问完 13 项后贴出 brief 全文等用户说"确认开工"。

## Q0 主体盘点 inventory（新增，先于一切风格讨论）

话术："说 8–12 件只属于你们、不属于竞品的东西：名字含义、门牌街道、关键数字、约束、材料颜色、仪式时刻、印刷品（票/牌/单）。"
每条追问："换竞品名还成立吗？"成立则删（品类物）或改（找独特变体）。
标注每条"图 query 可用？"（搜 inventory 词，不搜品类词）。

## Q1 行业 / 领域

- 推荐按用户原话先猜一个再问："听起来像【科技/SaaS】，对吗？"
- 选项示例：科技互联网 / 金融 / 教育 / 医疗健康 / 制造零售 / 政务公共 / 文化创意 / 其他（请说明）

## Q2 使用场景

选项：融资路演 / 内部汇报 / 对外提案销售 / 发布会演讲 / 课程培训 / 学术答辩 / 招投标 / 其他
追问：有无主讲人？现场讲还是会后自己看？（推导 reading_mode：讲者+视觉=presentation / 页+讲者=balanced / 近读自足=text；决定字量：演讲跟随版字少，阅读版字全）

## Q3 面对人群（谁在台下）

选项：投资人高管 / 客户决策人 / 同事跨部门 / 学生学员 / 评审专家 / 公众用户
话术："谁拍板？他们最在乎什么？"

## Q4 受众特点

选项：技术懂行 / 业务懂行但技术一般 / 完全外行 / 年轻偏好网感 / 严肃偏好稳重 / 时间极少只看结论
对应动作：外行→少术语多比喻；高管→先结论；时间少→每页一句话结论置顶。

## Q5 页数要求

选项：10页内精简版 / 15–20页标准版 / 30页以上完整版 / 不限你定
规则：演讲 1 分钟≈1–1.5 页；超过 30 页建议分章节+目录页。

## Q6 风格要求（风格卡单选，见 style-cards.md）

按 inventory + Mode 发 7 张卡（名碑/句版/色章/一motif/静器/暗房/纯字），用户选一。
话术："我按你的独特物推这张卡，你可以换；换须说理由（违品牌/缺资产），记入报告。"
品牌 VI 锁色/锁字：走 keep（只取构图），报告声明 + 自检单项放行。

## Q7 配色要求

先给 3 个 palette 方向（含浅/深各一），用户可指定品牌色（要 hex）或说"按风格定"。
必问：有没有企业 VI / Logo 主色不可动？深色还是浅色为主？

## Q8 预期效果

选项：拿下投资/订单（说服）/ 对齐决策（共识）/ 讲清一件事（理解）/ 留存传阅（资料）/ 考试过关（评审）
每个效果对应结尾页不同：说服→行动召唤+联系方式；共识→决策事项+分工；理解→一页总结；资料→目录+附录。

## Q9 输出格式

选项：PPTX 可编辑（推荐）/ PDF 定稿 / 两者都要（先冻 PPTX 再转 PDF）
说明：PDF 从终版 PPTX 转，不重排，保证一致。

## Q10 现有资料

选项：
- A 一段想法（一句话/几句）→ 我来搭框架+补论据（会标出待确认数字）
- B 零散资料（多文件/链接）→ 我先归纳再搭大纲
- C 现成大纲（章节标题有，内容缺）→ 按大纲填页
- D 详细内容文档（成段文字/数据）→ 提炼成页，不整段粘贴
- E 已有 PPTX（需美化/改版）→ 问：保文案逐页美化，还是打散重构？
让用户直接贴文本或给路径。收到后复述"我收到 X 个文件，理解为 Y，对吗？"

## Q11 论证骨 Mode（新增，决定标题声口与大纲节奏）

选项：`narrative`（路演/融资/品牌故事，标题是推进弧的 beat，**默认**）/ `pyramid`（投决/汇报，标题即结论断言，SCQA）/ `instructional`（培训/教程，标题=教什么，平行同构）/ `showcase`（发布/开场，标题短促，图数领衔）/ `briefing`（例会/手册，标题是 topic label，无 thesis）。
话术："这份 deck 想让听众**怎么被说服**？我按场景先推一个，你可以改。"
Mode 是 brief 必填项（`--confirm` 校验）；P2.0 只展开它的标题声口，不再重问。
