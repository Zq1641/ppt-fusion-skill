# P2–P3 设计美学 v2.1（taste house rules 全量 + ppt-master 色字锚）

把 taste-skill 的网页美学 + ppt-master 的执行锚翻译成幻灯片约束。违反"硬规则"必须返工。

## 1. 先有想法（一句话）+ 落页

格式：`【属于这个主题的独特东西】成为【全 deck 重复出现的视觉装置】`。原料只能来自 inventory Q0。
竞品测试：把竞品名代入还成立→重想。"干净高级"不是想法。
连续性工程：何物重复 + 变体（scale/crop/density/position 按页角色变）+ 跨页 Morph 候选命名。
想法必须活到最后一页（含致谢页），中途变回模板页即失败；每页 design-notes 写"本页装置在哪"，抽查不到即返工。

## 2. 配色（六角色 + 中性层 + 占比 + 禁令）

锁定：`bg / surface / ink / muted / accent / accent_ink` + 按 Style 推导中性层（分层板补 `surface+grid`、压图补 `scrim/overlay`、手绘补 `block-shade`）。
占比：ground 70–90%，accent 每屏 <5%（≤2 处），只打行动点 + 一处细节；surface 与 bg 只差 1 档 tone。
**场-ink 配对**：色场上不用 muted，用场 ink 全强度；次要用场 ink 70% 且过对比度。
深底用微 tint 深色 + 柔白字（非纯白），字减一 weight；章节整页换场硬切、不渐变，相邻场明度必跳。
HSL 禁令（除非品牌 VI 明确要求并在报告声明+自检单项放行）：奶油黄底（h22–62）+ 陶土橙（h6–30）同现 FAIL；单陶土 FAIL；单奶油 WARN；紫/靛（h244–295）FAIL。
派生 tint 留页内；新基色回 P2 修，构建器不许反写全局。

## 3. 字（少档 + 大反差 + 锚）

全 deck ≤2 种字体（中文标题/正文各一，西文数字同族），≤5 档字号（全 deck 计数，不只一屏）。
倍率锚（以 body 为 1）：封面 hero 2.5–5× / 章 2–2.5× / 页题·KPI 1.5–2× / 副 1.2–1.5× / lead 1.1–1.4× / 注 0.7–0.85× / 脚页码 0.5–0.65×；常驻角色全 deck 一锚。
标题 tracking −0.02~−0.05、leading 0.85–1.05；正文中文 ≥18pt / 西文 ≥16pt、leading 1.45–1.6、每行 ≤30 汉字。
标题≤2 行（宁删词不缩字，auto-fit 缩字藏溢出判负）；末行不单字（orphan 判负）；加粗只强调一处；标题与正文挂同一锚线（全 deck 2–3 条纵线，同栏 x 差 >4px 判负）。
数字表格 tabular；链接下划线不断尾。稀疏 display 特例全 deck 至多 2 次，第 3 次回 P2 命名角色。

## 4. 版式（相邻不重样 + 一屏一事 + 节奏）

一屏一事：一个论点 + 一组证据 + 一个视觉焦点；说不出 Audience move 的页是 outline 缺陷，不许装饰糊。
相邻两页必异构；写出全 deck layout 串，三现同形即模板，回 P2 换。
page_rhythm 每页一 tag：anchor（封面/章节/目录/收尾）/ dense（信息基线）/ breathing（真停顿，不许填料）。
留白：段距 > 行距 2 倍；标题上空 ≥ 下空 2 倍；节距明显大于节内。
封面 hook 必填 + 答三问；收尾 takeaway 必填（三式：全幅 Slogan / 反白封面复现 / 联系大字，禁"谢谢"空页、禁纯联系页、禁复刻封面）。
反模板清单（见即修）：三等分图标卡片行 / 英文小 caps / 细线分割一切 / 1px 描边盒 / 圆角 12px 卡套娃 / emoji / 渐变 blob / pill badge / 眉题小 label / 01/02 编号 / 等宽正文 / 题内变色斜体 / 玻璃 blur 卡（除非走暗房/玻璃卡并尽 scrim 义务）/ 灰条假 dashboard / 绿点中点串 / Step 复读。

## 5. 图（分级 + floor + 同比同处理 + scrim）

优先级：用户实拍/产品截图 > 按 palette 现画矢量 > 开源实景（注明来源+许可+署名）> 纯色+大字。搜 inventory 词，不搜品类词。
**真图 floor**：10–17 页 deck 真图 ≥4（SVG/图标/色块不计；quote/closing 纯字色场可豁免）。SVG 须配数/结论，不许纯饰；三级细节（远形/中层/近纹）。
同比同处理同方角（二选一：全直角/全同圆角）；拉伸/灰盒占位/网图冒充产品见即打回。
图上文字必 scrim（定向 0.88→0.30→0 守字侧 / 底 fade 0→0.72 托底题）或移出图外；无 scrim 图字对比度判负。
外来图下载进仓 + 页脚署名 + 报告列（题/者/许可/源页），绝不冒充自家产品。
